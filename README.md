# NoteSite — Static Website (Git Practice)

This repo is a small static website created to practice Git & GitHub workflows.

## What to practice
- branching, merging, PRs
- conflict creation & resolution
- rebasing and interactive rebase
- tagging/releases and GitHub Pages
- stashing, resetting, reverting
- submodules (optional): add a tiny 'assets' repo

## Quick start
```bash
git init
git add .
git commit -m "chore: initial static site"
```
